Reserva de Assentos – C++
Sistema simples em C++ para reservar assentos de um avião.
Marca posições, valida regras e mostra o mapa atualizado.

Funções principais


Escolher fileira (1–10)


Escolher poltrona (A–F)


Escolher tipo de passagem


Bloquear assentos já ocupados


Respeitar regras de Executivo/Econômico


Exibir mapa completo



Regras


Executivo: A–F liberados


Econômico: não permite A e F


Assento reservado → 'x'
